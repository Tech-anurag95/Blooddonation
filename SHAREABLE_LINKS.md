## 🔄 To Restart the Tunnels

If you need to restart, run these commands:

**Terminal 1 - Frontend:**
```bash
npx localtunnel --port 3000
```

**Terminal 2 - Backend:**
```bash
npx localtunnel --port 5000
```

Then update `client/.env` with the new backend URL and restart React.
