================================
ALL API ENDPOINTS READY
================================

Authentication:
  POST   /api/auth/register
  POST   /api/auth/login
  GET    /api/auth/me

Users:
  GET    /api/users/:id
  PUT    /api/users/:id
  DELETE /api/users/:id

Donors:
  GET    /api/donors
  GET    /api/donors/nearby
  GET    /api/donors/:id
  POST   /api/donors/register
  PUT    /api/donors/:id
  GET    /api/donors/:id/donations
  POST   /api/donors/accept-request

Requests:
  GET    /api/requests
  GET    /api/requests/pending
  GET    /api/requests/user/:userId
  GET    /api/requests/:id
  POST   /api/requests
  PUT    /api/requests/:id
  DELETE /api/requests/:id

HOW TO RUN
================================

Terminal 1 - Start Backend:
  cd server
  npm run dev

Terminal 2 - Start Frontend:
  cd client
  npm start
